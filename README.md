# clockmesh

Clock validation gates for mesh inputs before they hit prod.

**Site:** https://theworker02.github.io/clockmesh/

## Install / run

```bash
git clone https://github.com/theworker02/clockmesh.git
cd clockmesh
node src/cli.js
node --test
```
